¿Cómo se usa?

  1. Aprende. Cada actividad empieza con el objetivo, el vocabulario y la gramática que necesitas.
  2. Practica. Resuelve ejercicios cortos con retroalimentación inmediata.
  3. Habla. Escucha, repite y deja que el reconocimiento de voz te diga cuánto se entendió.
  4. Escribe y graba. Contesta tu actividad con pistas, graba tu audio y copia todo a tu Word.

Antes de empezar

  • Usa Google Chrome o Microsoft Edge para que funcionen el micrófono y el reconocimiento de voz. Cuando el navegador lo pida, elige Permitir.
  • Tu avance se guarda solo en este dispositivo y navegador. No se envía a ningún lado.
  • Este sitio es para practicar y preparar tus respuestas; no reemplaza el archivo oficial. Descarga el formato de cada actividad desde la plataforma, copia ahí tus respuestas y envía ese archivo para su revisión.
